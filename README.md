# homebrew-tap

Homebrew tap for [phd1000x-ux](https://github.com/phd1000x-ux)'s tools.

## Install

```bash
brew install phd1000x-ux/tap/<formula>
```

## Formulas

| Formula | Description | Upstream |
|---------|-------------|----------|
| `nbv`   | Fast terminal-native Jupyter notebook viewer | [nbv](https://github.com/phd1000x-ux/nbv) |

### nbv

```bash
brew install phd1000x-ux/tap/nbv
```

macOS arm64 binary only. For other platforms, install via Cargo:

```bash
cargo install nbv
```
